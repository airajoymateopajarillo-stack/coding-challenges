## Front-end Challenge — ON/OFF Toggle

**Description:** Created an interactive button that switches between ON and OFF when clicked.

**Concepts Used:**
- JavaScript event handling
- jQuery selectors and click events
- DOM text updates
- Boolean state management

**Expected Behavior:**
- Initial state: ON
- First click: OFF
- Second click: ON
